Procesos clave

Cuatro sistemas que se integran

El plan Élite construye y conecta cuatro componentes técnicos. Cada uno tiene su propia lógica de desarrollo y pruebas.

🎬

Animación 3D con Blender

Modelado, materiales e iluminación de una moto o accesorio. Animación de 5–8 segundos con movimiento de cámara, renderizado en formato MP4/WebM e integrado en el hero de la home.

💳

API REST de pasarela + webhook

Integración del payment intent, validación de firma, respuesta HTTP 200 inmediata al webhook y procesamiento en segundo plano con waitUntil para no bloquear la confirmación del pago. Se implementa con Bold como ejemplo; el adaptador permite pasar a Wompi, Mercado Pago u otra sin rehacer el checkout.

💬

API WhatsApp (virtud secundaria)

Notificaciones automáticas de "pedido confirmado" y "cita agendada". Plantillas de utilidad aprobadas por Meta, conectadas al webhook del pago para dispararse solo cuando el estado es aprobado.

📊

Dashboard a medida

Consultas SQL con agregación en Neon (sumas, agrupaciones, filtros). Endpoints protegidos en Next.js y componentes con librería de gráficos para mostrar ventas, stock y citas en tiempo real.

Cronograma

4 semanas, un desarrollo paralelo

Mientras el desarrollador construye el frontend, el animador 3D trabaja en paralelo para que el día 30 el clip ya esté integrado.

01Semana

Fundaciones y diseño

Setup del repositorio, arquitectura de datos y wireframes. La animación 3D arranca en paralelo con el brief.

  • GitHub + Vercel + estructura Next.js/TypeScript
  • Modelo de datos: productos, pedidos, stock, citas
  • Wireframes y sistema visual
  • Brief 3D al animador + modelos de referencia Paralelo
02Semana

Frontend y catálogo

Construcción de la experiencia de compra completa. Primer render 3D llega para revisión.

  • Home, catálogo por marca, detalle de producto
  • Carrito y flujo de checkout
  • Diseño responsive y usabilidad
  • Primer render 3D para feedback Paralelo
03Semana

Backend, pagos y WhatsApp

Integración de la pasarela (Bold como ejemplo) con webhook y notificaciones por WhatsApp. El clip 3D se ajusta según feedback.

  • Endpoints Node.js: productos, pedidos, stock
  • API REST de pasarela (ej. Bold) con payment intent + webhook
  • API WhatsApp para notificaciones de pedido y cita
  • Ajustes finales del clip 3D Paralelo
04Semana

Dashboard, citas y entrega

Cierre del panel de administración, calendario de citas y despliegue a producción con el 3D integrado.

  • Dashboard con consultas SQL agregadas en Neon
  • Calendario interactivo de servicio mecánico
  • Integración del clip 3D en la home
  • Pruebas E2E, corrección de bugs y despliegue
