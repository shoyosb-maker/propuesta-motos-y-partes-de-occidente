Procesos clave

Cuatro módulos, una experiencia coherente

Pasa el cursor sobre cada tarjeta para ver qué se construye por dentro.

🎯

Visor 3D interactivo

El cliente gira el producto con el dedo. Impacto visual real sin animación narrativa.

Qué se construye

  • Modelo GLB de un producto
  • Integración con model-viewer
  • Carga optimizada para móvil
  • Fallback en imagen estática
💳

API REST de pasarela + webhook

Payment intent creado desde el backend, validación de firma y confirmación asíncrona por webhook, sin bloquear el checkout del cliente. Se implementa con Bold como ejemplo; sirve igual para Wompi, Mercado Pago u otra.

Qué se construye

  • Payment intent por pedido
  • Validación de firma del webhook
  • Confirmación asíncrona del pago
  • Registro del pedido en Neon
💬

WhatsApp (notificaciones)

Confirmaciones automáticas de pedido y recordatorios de cita por API de WhatsApp Business.

Qué se construye

  • Plantillas de utilidad aprobadas
  • Trigger al aprobar un pago
  • Notificación de cita agendada
  • Log de envíos en el dashboard
📊

Dashboard con reportes

Panel de administración con ventas del día, pedidos pendientes y citas agendadas.

Qué se construye

  • Consultas SQL en Neon
  • Reportes de ventas y pedidos
  • Listado de citas pendientes
  • Acceso protegido para admin
Cronograma

4 semanas, entregas visibles cada semana

Al final de cada semana tienes algo funcional en una Preview URL de Vercel para revisar.

Semana 1

Fundaciones

Repositorio, deploy inicial y estructura base.

  • GitHub + Vercel configurado
  • Arquitectura de datos en Neon
  • Wireframes y sistema visual
  • Primer deploy (Preview URL)
Semana 2

Frontend y catálogo

Experiencia de compra navegable con visor 3D integrado.

  • Catálogo por marca y detalle de producto
  • Visor 3D interactivo integrado
  • Carrito y flujo de checkout con la pasarela
  • Diseño responsive
Semana 3

Backend y pagos

Integración de la API REST de la pasarela (Bold como ejemplo) con webhook y registro de pedidos.

  • Endpoints Node.js de productos y pedidos
  • API REST de pasarela (ej. Bold) con payment intent
  • Webhook con validación de firma
  • Registro de pedido aprobado en Neon
Semana 4

WhatsApp, dashboard y cierre

Notificaciones activas, dashboard funcional y entrega final.

  • API WhatsApp para notificaciones
  • Dashboard con reportes de ventas
  • Formulario de agendamiento de citas
  • Pruebas E2E y despliegue a producción
